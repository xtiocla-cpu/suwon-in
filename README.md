# SUWON:IN — 수원 청년 생활정보 웹앱

수원에 새롭게 정착한 청년을 위한 생활정보 링크 플랫폼의 첫 번째 기본 버전입니다.

## 사용 기술
- HTML: 화면 구조
- CSS: 디자인 및 모바일 반응형
- JavaScript: 메뉴 이동, 검색, 카테고리 필터
- 서버/데이터베이스: 사용하지 않음

## 내 컴퓨터에서 미리보기
1. ZIP 압축을 풉니다.
2. `index.html` 파일을 더블클릭합니다.
3. 크롬 또는 엣지에서 화면을 확인합니다.

인터넷 연결이 있으면 웹폰트가 적용됩니다. 웹폰트 연결이 안 되어도 기본 글꼴로 표시됩니다.

## GitHub Pages로 공개하기
1. GitHub에 로그인합니다.
2. 오른쪽 위 `+` → `New repository`를 선택합니다.
3. 저장소 이름을 `suwon-in`으로 입력합니다.
4. `Public`을 선택하고 저장소를 만듭니다.
5. `Add file` → `Upload files`를 누릅니다.
6. 압축을 푼 폴더 안의 파일과 폴더(index.html, css, js, data, README.md)를 업로드합니다.
   - 주의: ZIP 파일 하나만 올리는 것이 아니라 압축을 푼 내부 파일을 올려야 합니다.
7. 아래 `Commit changes`를 누릅니다.
8. 저장소의 `Settings` → 왼쪽 `Pages`로 이동합니다.
9. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
10. Branch는 `main`, 폴더는 `/(root)`를 선택하고 `Save`를 누릅니다.
11. 잠시 기다린 뒤 Pages 화면에 표시되는 주소로 접속합니다.
   - 보통 주소 형식: `https://깃허브아이디.github.io/suwon-in/`

## 콘텐츠 수정하기
- 첫 화면 카테고리와 빠른 링크: `js/app.js`의 `categories`, `quickLinks`
- 각 메뉴에 보이는 정보 카드: `js/app.js`의 `sampleItems`
- 디자인: `css/style.css`
- 메인 화면의 큰 문구와 기본 구조: `index.html`

## 현재 버전의 범위와 한계
- 정책·장소 정보는 예시 링크와 안내용 콘텐츠입니다. 게시 전 공식 출처와 신청 조건을 직접 확인해야 합니다.
- 실시간 정책 자동 수집, 회원가입, 관리자 페이지, 사용자 간 동기화는 포함하지 않습니다.
- GitHub Pages는 정적 파일을 제공하므로 서버 프로그램이나 데이터베이스가 필요 없는 범위에 적합합니다.
- 외부 링크는 새 탭에서 열립니다.

## 운영 팁
- 정보마다 최종 확인일을 기록하는 필드를 추가하는 것을 권장합니다.
- 신청기간이 있는 정책은 마감일과 상태(모집중/마감/상시)를 관리하세요.
- 외부 사이트의 로고·사진·설명문을 사용할 때는 이용 조건과 저작권을 확인하세요.
